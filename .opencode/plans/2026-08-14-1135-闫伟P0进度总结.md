## Critical Context（隐含知识，无法从代码推断）

- 知识库曾加 DocumentImage 后删（0017），默认嵌入模型已切 `qwen3-vl-emb-2b`，`embed_image()` 此前无调用方
- knowledge 占位符必须用 `{{IMAGE:N}}`（前端 DocumentDetailModal 按 image_index 匹配），不能用 requirements 的 `docimg://` 格式
- 前端知识库图片 UI 是死代码，后端补齐 `resolved_images` 数据即自动生效
- Agent Loop 是「单 Agent + 中间件」模式（create_agent），LLM 为全局单模型
- httprunner 是 vendored HttpRunner 3.x，同步串行，压测必须另起 Locust
- Locust CSV 中 Aggregated 行 `Type` 空、`Name`=="Aggregated"（按 Name 匹配，非 Type）
- Django OneToOne 反向不存在抛 `DoesNotExist`（非返回 None），serializer 里 `plan`/`report` 需 try/except 或 SerializerMethodField
- 渲染器：有 variables/validators 时请求渲染为 `resp = self.client.request(...)`，否则 `self.client.request(...)`；变量提取 `self.<name> = resp.json()["<path>"]`；占位符 `{{name}}` → `self.<name>`
- UI 自愈定位失效关键词：`('定位器','定位元素','元素定位','元素不存在','Element not found')`；执行器失败消息见 executor.py:724/778
- Celery 任务走默认 `celery` 队列（worker 监听 `-Q celery,task_center`）
- Dockerfile 已补 `COPY code_coverage/`、`COPY perf_test/`（此前遗漏，否则容器迁移报模块缺失）
